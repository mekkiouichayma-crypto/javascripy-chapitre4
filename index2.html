1. Définition Étape 1 / 10

★ Tout expert a un jour écrit son tout premier alert(). Le tien, c’est maintenant !

JavaScript est un langage de script interprété (lu et exécuté ligne par ligne) et côté client (il s’exécute dans le navigateur, pas sur le serveur). HTML = structure, CSS = style, JavaScript = comportement.

  • Modifier le contenu HTML et CSS sans recharger la page.
  • Vérifier les formulaires (ex. un champ vide).
  • Rendre la page interactive : clics, saisies, survol…

2. Intégration Étape 2 / 10

★ Un petit fichier, une petite balise… et ta page devient vivante.

Inline : le code est entre les balises <script> et </script>. Externe : le code est dans un fichier .js, lié avec l’attribut src.

<script>
  alert("Bonjour !");
</script>

<script src="script.js"></script>
À retenir : la méthode externe est la meilleure pratique : code mieux organisé et réutilisable.

5. Les boîtes de dialogue Étape 5 / 10

★ Poser des questions, c’est le début de l’apprentissage, même pour un programme !

  • alert() : affiche un message.
  • confirm() : demande confirmation, retourne true ou false.
  • prompt() : demande une saisie, retourne toujours du texte.
let a = prompt("Entrez un nombre");  // "10" (texte)
let n = parseInt(a);                 // 10 (entier)
if (Number.isNaN(n)) alert("Pas un nombre !");

parseInt() convertit en entier, parseFloat() en réel, Number.isNaN() vérifie si la conversion a échoué.

6. Les structures sélectives Étape 6 / 10

★ SI tu continues à pratiquer, ALORS tu réussiras. Et le else ? Il n’existe pas !

if (note >= 16) {
  alert("Très bien");
} else if (note >= 10) {
  alert("Admis");
} else {
  alert("Ajourné");
}

switch (jour) {
  case 1: alert("Lundi"); break;
  case 2: alert("Mardi"); break;
  default: alert("Autre jour");
}

if = une condition, if…else = deux possibilités, else if = plusieurs conditions. switch compare une variable à plusieurs valeurs : break sort du switch, default = aucun cas ne correspond.

7. Les structures itératives Étape 7 / 10

★ Répète, répète, répète : c’est comme ça qu’on devient bon, dans la vie comme dans une boucle for.

BoucleQuand ?
fornombre de répétitions connu (initialisation, condition, incrémentation)
whiletant que la condition est vraie (testée avant)
do…whileau moins une exécution (testée après)
for (let i = 1; i <= 5; i++) { console.log(i); }

let j = 1;
while (j <= 5) { console.log(j); j++; }

let k = 1;
do { console.log(k); k++; } while (k <= 5);
À retenir : oublier i++ crée une boucle infinie qui bloque la page.

8. Les fonctions Étape 8 / 10

★ Écris une fonction une seule fois, utilise-la mille fois. Comme tes efforts !

Une fonction est un bloc d’instructions réutilisable. function la déclare, les paramètres sont les données reçues, return renvoie un résultat, et l’appel l’exécute.

function direBonjour() { alert("Bonjour"); }        // 1. sans param, sans retour
function saluer(nom) { alert("Bonjour " + nom); }   // 2. avec param, sans retour
function getAnnee() { return 2026; }                // 3. sans param, avec retour
function somme(x, y) { return x + y; }              // 4. avec param, avec retour

let r = somme(3, 4);   // r vaut 7

9. Le DOM Étape 9 / 10

★ Tu as maintenant le pouvoir de transformer une page web. Amuse-toi, ose !

Le DOM (Document Object Model) permet à JavaScript d’accéder aux éléments HTML et de modifier leur contenu, leur structure et leur style.

MéthodeRésultat
getElementById()un élément par son id
querySelector()le premier élément qui correspond à un sélecteur CSS
getElementsByClassName()tous les éléments d’une classe
getElementsByTagName()tous les éléments d’une balise

Propriétés : textContent (texte), innerHTML (HTML), value (valeur d’un champ), id, tagName.

let t = document.getElementById("titre");
t.textContent = "Nouveau titre";
t.style.color = "red";
t.style.cssText = "color: blue; font-size: 20px;";
t.classList.add("important");
t.classList.remove("important");
